# SelfTube

SelfTube — это родительский фильтр видео для детей. Родитель самостоятельно
подбирает разрешённые каналы и отдельные видео с Rutube в админ-панели, а
ребёнок смотрит **только** то, что одобрено, в удобном YouTube-подобном
интерфейсе — без алгоритмических рекомендаций, «похожих видео» и бесконечной
ленты. В версии 1 поддерживается только Rutube, но архитектура построена на
платформенных адаптерах, поэтому позже можно добавить VK, OK и другие
источники.

## Технологии

- **Next.js 14** (App Router)
- **TypeScript**
- **Prisma + SQLite**
- **Tailwind CSS**
- **Vitest** (тесты)

## Установка и запуск

```bash
npm install
cp .env.example .env   # затем отредактируйте значения (DATABASE_URL, SESSION_SECRET)
npm run db:push
npm run db:seed
npm run dev
```

После `npm run db:seed` создаётся аккаунт родителя по умолчанию:

- **Логин:** `parent@example.com`
- **Пароль:** `changeme123`

Значения можно переопределить переменными окружения `SEED_PARENT_EMAIL` и
`SEED_PARENT_PASSWORD` перед запуском сида.

## Как пользоваться

**Родитель** работает в админ-панели по адресу `/admin`:

1. Войдите под аккаунтом родителя.
2. Вставьте ссылку на канал или отдельное видео Rutube, чтобы одобрить его.
3. Нажмите **«Синхронизировать»**, чтобы подтянуть новые видео из одобренных
   каналов.
4. В разделе **«Настройки»** задайте дневной лимит просмотра.

**Ребёнок** пользуется приложением по адресу `/` (главная):

- просматривает сетку одобренных видео;
- ищет видео внутри одобренного каталога;
- нажимает на видео, чтобы начать просмотр.

## Ограничения версии 1

- **Только Rutube** (VK/OK планируются позже).
- **Один общий список** для детей — без отдельных профилей на каждого ребёнка.
- **Простой встроенный планировщик синхронизации** (в процессе приложения, раз в
  6 часов) плюс кнопка ручного запуска.
- **Одна семья** — архитектура готова к SaaS, но пока не мультитенантная.

## Проверка строгой изоляции (ручная)

После того как через `/admin` добавлено хотя бы одно реальное видео Rutube,
человек должен вручную проверить на настоящем устройстве/в браузере следующий
чек-лист:

1. На `/watch/<id>` нажатие по области плеера **не** уводит со страницы и **не**
   открывает новые вкладки (sandbox).
2. Собственный логотип Rutube, блок «похожих видео» и ссылки **не** кликабельны
   сквозь наш оверлей.
3. Когда видео заканчивается, появляется **наш** экран «Видео закончилось» с
   подборкой из каталога (а не сетка «похожих» от Rutube).
4. Удалённое/сломанное видео показывает «Видео временно недоступно»
   (fail-closed), а не неуправляемый плеер.
5. Детский поиск возвращает только элементы из одобренного каталога.
6. При достижении дневного лимита появляется «На сегодня всё!», и воспроизведение
   блокируется.
